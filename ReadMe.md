## **Project Setup and Installation**

Everything should honestly work out of the box. You will need Cisco Packet Tracer installed which can be found [here](https://www.netacad.com/cisco-packet-tracer). This is not a tutorial on how to navigate Cisco Packet Tracer, so if you need more guidance reference their documentation as linked.
